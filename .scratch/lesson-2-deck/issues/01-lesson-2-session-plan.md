Per segment the plan must fix:

Nothing is re-explained. Then the debrief: 2–3 volunteers, 10–15 minutes, what they show, how common problems are captured.
- **Segment 2 — The sensitive-data rule and data-protection principles.** The two-lane rule as a routing decision (Sensitive Lane vs. Daily Driver, in CONTEXT.md terms); the data-protection principles; the key points of the dean's directive 1/2026 (III.26.) — human oversight and final responsibility, transparency and documentation of AI use, no personal, sensitive or unpublished data into external AI tools without explicit permission, AI in institutional administration allowed within data-protection rules, critical checking of every output, consequences of breaches — as brief reference points citing the document, not slides reproducing it; the anonymise-before-upload rule for documents with personal or sensitive content; the "what must never enter Gemini" list. The directive's rector-level parent (4/2025. (X. 28.)) is named as the umbrella rule. No YouTube references.
- **Segment 3 — Copilot Chat (Basic) in practice.** Sensitive Lane use cases (internal administration, unsubmitted proposals, personnel matters, strategic financial planning); the limits and guardrails (no SharePoint/OneDrive grounding, enterprise behaviour); then one use case per tool in the compiled tool list: Adobe Acrobat (free-to-use features only, premium and AI Assistant flagged as not available), Prompt Coach (tied back to meta-prompting), Study and Learn (concept explanation, flashcards, quizzes for learning outcomes), Canva via the Teams app for presentation prototyping, and genspark.ai as the tool for the actual presentation. The demo script names which use case is run live. Gemini is not mentioned in this segment.
- **Segment 4 — Gemini in depth.** Every free-tier capability beyond Copilot: file and image upload, long context, Gems as persistent context (this is the Level 3 move — dedicated workspaces that already know your domain), Deep Research, Canvas for structured outputs and drafts, Google Workspace hooks, plus anything else the free tier offers at the time of writing — the plan says which are demoed live. NotebookLM at use-case level only: YouTube link turned into a textual source, several documents aggregated in one notebook, notebooks imported into Gemini as project folders. Copilot is not mentioned in this segment. The plan flags that feature availability is re-verified the week before delivery.
- **Segment 5 — Assignment + close.** The assignment ready for a slide: chain all tools and capabilities introduced in the course so far into a multi-step workflow orchestration; produce a blueprint of the tool chaining and the workflow steps with detailed guidelines and a justification for each step; the deliverable is a presentation on a hand-picked topic designed for educational purposes and intended to facilitate learning outcomes; sensitive steps must be routed to the correct lane. The stated outcome: Level 3 achieved, foundation for Level 4 established. Effort expectation and where the work is shown (Practice Week 1 drop-in, Lesson 3 debrief). The close points to Practice Week 1 (W3) and Lesson 3 (NotebookLM, Perplexity, Wiki Sandbox).
