# New profile versions carry the Golden Scenario forward, with human-approved figures

Every Funding Profile version is pinned to its own Golden Scenario, so a new version needs one before its Synthetic Check means anything. Working out every expected figure by hand again for each version is too costly for a change as small as one unit-cost amount. So a new version carries its predecessor's Golden Scenario forward, with the same Shape Parameters and the same fake inputs. The budget-profile-maintainer recomputes the expected figures under the new version with the reference model and lists each figure that changes. The human approves that list, quoting the proposal's id, before anything is written. That is why the maintainer proposes expectations before it runs the Synthetic Check, the reverse of the order in the spec: the check needs the approved Golden Scenario to check against.

**Consequences**: For a version after the first, the independent anchor is the human's review of the changed figures, each traced to a row of the profile diff, not a fresh hand computation. Every unchanged figure stays as hand-worked for the first version. A section of expected figures the maintainer cannot recompute stops the proposal, and a human works those figures out. An accepted version's Golden Scenario transcription is digested with the version and is as immutable as it is.
