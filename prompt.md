A fundamental limitation has been introduced regarding the course, in that only the 'Copilot Chat (Basic)' licence is available. This prevents it from being used with other Office tools, such as SharePoint and OneDrive, which should be its biggest benefit. This issue is further exacerbated by the fact that Microsoft 365 Copilot is designed for enterprise environments, where
•	Data leakage is a major concern
•	Compliance requirements are strict
•	Outputs must be auditable
•	Hallucination risks must be reduced.
Therefore, it performs more poorly on tasks than other providers (Claude, ChatGPT), and is less capable, even when the model itself is strong.
Only two benefits come with Copilot. First, Copilot Chat is authorised to process sensitive and IP-sensitive data and can be used for tasks involving internal administration, unsubmitted grant proposals, personnel information, strategic financial planning, etc. Therefore, Copilot Chat should only be used for these cases, and another free-tier provider should be sought for specific tasks that do not include sensitive institutional data. 
The second benefit is the Agent Store, where you can find agents such as 'Perfect Wiki', 'Adobe Acrobat for Microsoft Teams, Outlook, and Copilot', 'Asana', 'Prompt Coach', and the possibility to create custom agents or use agent templates. Since the 'Workflows (Frontier)' agent is disabled the custom agent capability should be used to achieve similar capabilites, by the end of the course, once the basics are in place.

The course will be hosted online, with each session lasting 1.5 hours.
The course length is not definitive, but it should span around 5–8 weeks. There should be 'blank' lessons where participants can practise and complete the assignment, since the course will take place during office hours.

Each lesson will build on what was covered in the previous one, but the general structure should remain the same. 
Therefore, only the first lesson needs to be planned in detail. This should be an introduction to LLM Fundamentals, prompt engineering, vibe coding, and so on, built around the '7 Levels Framework'. Additional sources will be provided for this.

Initially, the course should focus on general research management. Specific tasks and use cases, such as creating detailed budgets and writing proposals, should be optional parts of the course after the knowledge management system has been created.

Apart from Microsoft 365 Copilot, the course only allows the use of free-tier AI tools.
